# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-07-16

### Added
- Initial public release of the Capstone project.
- MADDPG v3 training code for a 3-robot PyBullet mining environment (`src/`).
- ROS 2 (Humble) + Gazebo robot description and arena world (`simulation/`).
- The finalized training run: log, plots, interactive dashboard, and the final
  policy checkpoint (`results/`).
- Standalone analysis / plotting scripts (`analysis/`).
- Design reference and parallel-rollout documentation (`docs/`).
- Project metadata: README, MIT license, requirements, CI, and community files.
