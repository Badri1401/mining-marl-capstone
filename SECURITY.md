# Security Policy

## Reporting a Vulnerability

This is a research / capstone project and is provided as-is. If you discover a
security issue, please **do not** open a public issue. Instead, contact the
maintainers privately via the email associated with the GitHub account
[@Badri1401](https://github.com/Badri1401).

We will acknowledge your report and respond as soon as reasonably possible.

## Scope

The code here is intended for simulation and research use. It is not hardened for
production deployment on physical robots without additional safety review.
